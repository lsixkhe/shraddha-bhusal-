Generative AI · Hackathon

Momentum — Anti-Procrastination Study Companion

Built for the GDG Build with Gemma Hackathon at the University of Aberdeen (July 2026). Momentum is a Streamlit-based web app that turns a syllabus into a realistic, day-by-day study plan and provides a 2-minute "momentum starter" for any topic a user is avoiding.

  • My Role: AI Integration & User Interface Design.
  • Technical Contributions: Integrated Gemma 4 (via Google AI Studio) for syllabus decomposition and micro-action generation. Wrote deterministic scheduling logic in Python to ensure dates were never hallucinated. Used Streamlit to build the front-end interface.
  • Challenge Overcome: Small models sometimes return malformed JSON. I built a robust extractor and prompt engineering pipeline (temperature 0.2, explicit schema) to ensure reliability. Separating deterministic logic from generative logic was key to delivering a working demo under strict hackathon time pressure.
